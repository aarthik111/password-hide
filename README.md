🔐 Password Toggle UI

A simple and clean password input component with a show/hide toggle feature using an eye icon. Built with HTML, CSS, and vanilla JavaScript.
✨ Features

    Toggle password visibility by clicking the eye icon

    Modern UI with responsive design

    Styled using Poppins font and soft color palette

💻 Technologies Used

    HTML5

    CSS3

    JavaScript (ES6)

📁 How to Use

    Clone the repo or download the files.

    Open index.html in your browser.

    Type in the password field and click the eye icon to toggle visibility.
